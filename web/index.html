Mars Lander – Genetic Algorithm Simulator

Quick Start

  1. Pick a terrain from the list below
  2. Adjust parameters, or keep the defaults
  3. Click Run Algorithm
  4. Use playback controls to step through each generation

In the viewer: green line = landing zone · red lines = terrain

  1. 1
    Initialise

    Create a population of random landing command sequences : the algorithm's first guesses.

  2. 2
    Evaluate

    Simulate each lander and score it: how close to a safe landing did it get?

  3. 3
    Select

    Pick the highest-scoring landers as parents : better landers have a better chance.

  4. 4
    Crossover

    Combine parts of two parents' command sequences so offspring inherit the best of each.

  5. 5
    Mutate

    Randomly tweak a few commands to keep diversity and avoid getting stuck.

Repeat until a lander lands safely : or the generation limit is reached.

Mission Control

Each terrain tests the algorithm's adaptability in different ways.

More landers = broader exploration per generation.

More generations = more improvement opportunities.

Tournament is balanced; Roulette rewards top performers more aggressively.

The best landers survive unchanged. Too high: diversity drops. Too low: good solutions are lost.

High: offspring blend both parents' strategies. Low: offspring resemble one parent closely.

Low: stable but may stagnate. High: explores widely but can disrupt good solutions.
